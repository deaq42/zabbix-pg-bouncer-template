# PgBouncer для Grafana 10.4

Файл импорта: [pgbouncer_grafana_10_4.json](pgbouncer_grafana_10_4.json).
Использует метрики **Template PgBouncer by agent 6.0** из этого репозитория.
Источник данных — Zabbix, Prometheus/exporter не требуется.

## Установка

Проверяемая комбинация: **Grafana 10.4.19**, **Grafana-Zabbix 4.6.1**,
**Zabbix 6.0.48**. Использованы встроенные панели Grafana: Stat, Time series, Row.

1. Установите совместимый плагин Zabbix:

   ```bash
   grafana-cli plugins install alexanderzobnin-zabbix-app 4.6.1
   sudo systemctl restart grafana-server
   ```

   Версия 4.6.1 поддерживает Grafana >=9.3.0. Не устанавливайте последнюю
   версию вслепую: у новых выпусков плагина другой минимальный Grafana.
   При необходимости включите приложение Zabbix в настройках плагинов Grafana.

2. В **Connections → Data sources** создайте источник **Zabbix**:
   укажите URL API вида `https://zabbix.example/api_jsonrpc.php` и учётную
   запись с правом чтения нужных групп хостов и истории элементов данных.
   Проверьте подключение кнопкой **Save & test**. Прямое подключение Grafana
   к базе данных Zabbix для этого дашборда не требуется.

3. Откройте **Dashboards → New → Import**, загрузите JSON и нажмите **Import**.
   На дашборде выберите **Источник Zabbix**, **Группу** и **Хост**,
   к которому привязан исправленный шаблон. Хост выбирается один.

4. Выберите базы и пулы (`пользователь@база`) или оставьте **All**. Списки строятся по
   обнаруженным элементам шаблона; для нового хоста нужно дождаться LLD
   и хотя бы двух сборов для скоростей счётчиков.

## Что показывает

- **Обзор экземпляра:** последнее состояние, запросы/с, транзакции/с,
  количество пулов и пользователей, среднее время ожидания.
- **Все базы:** общие скорости, длительности, трафик и средние скорости,
  которые вычисляет сам PgBouncer за `stats_period`.
- **По базам:** запросы и транзакции, длительности, трафик, размер пула,
  серверные и клиентские подключения вместе с их лимитами.
- **По пулам:** активные/ожидающие клиенты, состояния серверных соединений,
  максимальное ожидание и режим пула.
- **Внутренние списки:** используемые и свободные структуры клиентов/серверов.

Фильтры базы и пула не меняют общие метрики экземпляра — это явно
обозначено в заголовках «все базы»/«экземпляр». Фильтр пула не меняет статистику
базы, которую PgBouncer выдаёт без деления по пользователям. Полное имя пула
сохраняется целиком, без попыток отделить пользователя по символу `@`.
База дополнительно проверяется по тегу элемента `Application: PgBouncer: <база>`.
Если разные пары пользователь/база дают одинаковое отображаемое имя пула,
выберите конкретную базу для их различения.

Длительности поступают в секундах; Grafana автоматически выбирает удобный
масштаб отображения. `maxwait_us` уже переведён в секунды сборщиком шаблона.
Счётчики запросов, транзакций и байтов уже преобразованы Zabbix в скорости,
повторное вычисление производной в дашборде не применяется. Трафик — **байты/с**.

Нулевой лимит подключений означает **без ограничения**, поэтому процент
заполнения не вычисляется. `pool_size` не используется как лимит клиентов.
`free_clients` и `free_servers` — свободные структуры памяти PgBouncer,
а не число дополнительных подключений, которые разрешено открыть.

По умолчанию выбран интервал 6 часов, обновление — 30 секунд. Нет данных
отображается как отсутствие данных, а не как ноль. Интерполяция пропусков плагином
отключена; графики разрываются при расстоянии между точками больше 90 секунд.
Панель состояния показывает
последнюю запись в выбранном интервале; для проверки доступности используйте
также триггеры `nodata` в Zabbix. Цветовые пороги карточки среднего ожидания
заданы в Grafana: 0.1 и 1 секунда; они не синхронизируются с макросами Zabbix.

Проверка выполнялась на сохранённой истории лабораторного PgBouncer без
повторного запуска остановленного стенда. JSON содержит только настройки
дашборда, без паролей, адреса сервера, идентификаторов элементов или тестового хоста.

Схема запросов и требования плагина:
[Grafana-Zabbix 4.6.1](https://github.com/grafana/grafana-zabbix/tree/v4.6.1).
